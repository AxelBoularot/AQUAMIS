- Mettre en partage de connection ton téléphone
- Brancher le raspberry sur secteur et mettre ton ordinateur sur la conection de ton téléphone
- Brancher le cable ethernet sur ton pc et sur le raspberry
- Lancer l'application "Realvnc"
- Clique sur l'icone correspondant à l'adresse ip : "169.254.0.2"
- Une fois sur le raspberry lance un terminal et exécute les commandes suivantes : 

source venv/bin/activate
python3 /home/boula/Desktop/code_emetteur_or.py

- tu verras alors dans le terminal que les ports 9999 et 8888 sont disponible et que le code est en attente de connection
- Sans fermer les autres fenetres ouvre l'application "Visual Studio Code" et ouvre le code "Interface_V3" puis lance le code
- Une fois le code lancer clique sur "start" puis entre "a" en mot de passe, tu sera alors sur l'Interface, la connection devrait se faire automatiquement



Cas particulier : 

si dans le terminal du raspberry la dernière ligne à un morceau vert c'est que le code n'est plus exécuté
dans ce cas relance le avec la commande suivante : python3 /home/boula/Desktop/code_emetteur_or.py
dans le cas ou ça ne fonctionne pas débranche et rebranche le raspberry tout en cliquant sur "Emergency stop" sur l'interface de controle
puis une fois les commandes refaites clique sur "already running"

Si le raspberry n'est pas détecté sur realvnc attend le temps que le raspberry démarre si tu viens de le brancher sinon utilise l'adresse ip du raspberry sur le réseau de ton partage
"192.168.37.***" un truc comme ça (déjà enregistrer dans realvnc)
